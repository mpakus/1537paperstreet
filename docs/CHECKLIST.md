# 1537paperstreet — чеклист работ

Задачи для AI-агентов. Читать вместе с `PLAN.md` и `AGENTS.md`.

**Правила работы с этим файлом**

- Одна задача = один PR = одна ветка `task/T-xxx-short-name`.
- Задача считается закрытой, только когда выполнены **все** пункты Definition of Done (см. `AGENTS.md`) и критерии приёмки самой задачи.
- Зависимости указаны в скобках: `(← T-012)` значит «нельзя начинать, пока не закрыта T-012».
- **ID задач стабильны и не связаны с порядком фаз.** Фаза P9 (редактор) была добавлена позже, поэтому её номера T-160+ идут после T-105+. Ориентироваться на порядок фаз, а не на числа в ID.
- Не менять формулировку задачи. Если задача сформулирована неверно — открыть issue и остановиться.
- Не выходить за рамки задачи. Рефакторинг «заодно» — отдельная задача.

Легенда: `[ ]` не начато · `[~]` в работе · `[x]` готово · `[!]` заблокировано
