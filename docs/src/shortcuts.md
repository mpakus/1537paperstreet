# Keyboard shortcuts

Working in the reader:

| Keys | Action |
| --- | --- |
| ⌘N / ⌘⇧N | New file / new folder |
| ⌘O | Open File… |
| ⌘P | Quick-open a file |
| ⌘⇧P | Switch project |
| ⌘F | Find in preview |
| ⌘G / ⌘⇧G | Next / previous find match |
| ⌘1 / ⌘2 | Hide projects / tree |
| ⌘E | Preview / editor |
| ⌘⇧E | Split |
| Escape | Leave full-size preview |
| ⌘S | Save |
| ⌘, | Settings |
| ⌘⌥E | Export the open document to PDF |
| ⌘⌥T | Light / dark theme |
| ⌘⌥A | Assistant tab |
| ⌘+ / ⌘− / ⌘0 | Larger / smaller / reset type |
| ⌘⇧R | Reveal in Finder |
| ⌘⇧O | Open in External Editor |
| ⌘⌫ | Move to Trash |

The same actions appear in the title bar: Preview / Edit / Split,
Save, Export, Board, AI. In Preview and Split on the right — A− / A+ (type
size) and − / % / + (preview zoom). Full size sits in the preview corner.
Formatting (⌘B / ⌘I / ⌘K) appears in Edit. Settings — File → Settings… or ⌘,.
Find and replace (⌘⌥F) is still ahead.

In the Assistant composer: Shift+Enter, Ctrl+Enter, or ⌘Enter send; Enter
inserts a newline. Escape does not cancel a running turn — use **Stop**.
